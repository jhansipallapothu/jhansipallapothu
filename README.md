## About Me

I'm an **Embedded Engineer II at Boson Motors**, working on real-time vehicle control unit
(VCU) firmware for electric vehicles — RTOS integration on PowerPC MCUs, hardware-in-the-loop
testing, and the diagnostic tooling that bridges firmware internals to the technicians who
service the vehicles.

- 🔧 Architected the **VCU Unified Diagnostic Suite** (Python/PyQt5), now a standard tool for company technicians
- 📡 Working across **CAN, UART, SPI, I2C** and automotive HIL testing
- 🧠 Building control logic with **ETAS ASCET, Stateflow, and Ansys SCADE** (Model-Based Development)
- ✅ Achieved **98% code coverage** on VCU firmware through comprehensive unit testing
- 🎓 B.Tech in Electronics & Communication Engineering, JNTUK — CGPA 8.97
- 🧑‍🏫 Mentored 15+ students in embedded systems integration at a national-level hackathon (ACE @SRKR)
